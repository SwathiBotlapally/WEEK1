# 🎯 Personal Introduction Program

## 📌 Project Overview
The **Personal Introduction Program** is a beginner-friendly Python project that interacts with the user by asking basic personal details and displaying a friendly welcome message.  
This project helps in understanding core Python concepts like input handling, variables, string formatting, and clean project structure.

---

## 🎯 Project Goals and Objectives
- Learn how to take user input using `input()`
- Store user data using variables
- Display formatted output using f-strings
- Improve interaction and user-friendly output
- Follow a proper GitHub project structure

---

## 🛠️ Technical Requirements
- Python 3.x
- Use `input()` to collect user information
- Minimum of **3 user questions**
- Use variables to store inputs
- Friendly and formatted output using `print()`

---

## 🗓️ Step-by-Step Development Plan

### Day 1: Setup & First Program
- Install Python
- Create project folder
- Write a basic Hello World program

### Day 2: Add User Input
- Ask for user name, age, and hobby
- Store responses in variables

### Day 3: Welcome Message
- Display personalized message using f-strings

### Day 4: Enhance Program
- Add extra questions (city, favorite color)
- Improve formatting and readability

### Day 5: Finalize & Test
- Add comments
- Test with different inputs
- Fix errors
